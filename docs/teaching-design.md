# Teaching Design

## 核心設計原則

模擬器不是把 MC 題包裝成遊戲。

學生需要：

```text
觀察症狀
→ 選擇工具
→ 收集 Evidence
→ 嘗試處理
→ 觀察 Consequence
→ 修正判斷
→ Fix
→ Summary
→ 個人提交
```

## 小組與個人 assessment

學生可以和組員討論，但每位學生使用自己的裝置、自己操作及自己提交。

因此教師可以比較：

```text
Group discussion result
vs
Individual understanding
```

## 錯誤操作

錯誤操作不會立即顯示「Wrong」。

例如：

```text
電腦慢
→ 執行 Disk Cleanup
→ Storage 增加
→ CPU 仍然 97%
→ 電腦仍然慢
```

學生需要自己重新判斷。

## Firewall

關閉防火牆後：

- 不會直接宣稱「電腦已被 hack」
- 會模擬安全風險上升
- 顯示未知連線嘗試
- Alert 可以移動
- Alert 不能 Close
- 必須在 Firewall App 重新開啟 Firewall

學習重點：

```text
Working ≠ Appropriate
```
